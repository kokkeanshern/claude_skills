# claude_skills

Generic Claude skills. TBH mostly written by Claude itself...

| Skill | What it does |
|---|---|
| [`sheets_bridge`](sheets_bridge/) | Cell-level read/write access to Google Sheets via an Apps Script web app — the gap left by the built-in Google Drive connector, which can only rename and move files. |
| [`whatsapp_bridge`](whatsapp_bridge/) | Use Claude as a linked device to send messages and poll (inbound) messages. |
